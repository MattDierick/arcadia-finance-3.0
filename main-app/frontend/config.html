AI Chatbot — LLM Configuration
Configure your OpenAI-compatible LLM endpoint. Aria will use these settings for all chat interactions. Accepts a base URL or a full endpoint URL (Azure OpenAI, etc.).
Base URL (OpenAI / Ollama / LM Studio): e.g. https://api.openai.com — /v1/chat/completions is appended automatically.
Full endpoint (Azure OpenAI): paste the complete URL including deployment path and ?api-version= — it is used as-is. Azure API key is sent as api-key header automatically.
